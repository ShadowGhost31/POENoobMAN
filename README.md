# PoE Noob Man

Оверлей-помічник для левелінгу в Path of Exile: підказки за гайдом білда поверх гри, наступна нода дерева і таймер забігу зі сплітами, як у спідранерів.

Вбудовані гайди (патч 3.29):

- [Arma Crema Scion](https://maxroll.gg/poe/build-guides/arma-crema-scion-leveling-build-guide). Опції: мул-Відьма, Shield Charge або Leap Slam, шлях в Act 6.
- [Rain of Arrows Deadeye](https://maxroll.gg/poe/build-guides/rain-of-arrows-deadeye-leveling-build-guide). Опції: Rain of Arrows або Lightning Arrow, Manaforged і/або Ballista, асценд Occupying Force або Focal Point. Пасивне дерево в цьому гайді є лише картинкою, тому в застосунку відстежується тільки порядок асценду.

## Можливості

- **Оверлей поверх гри.** Зона, рівень і очки дерева; до N поточних кроків з номером акту; наступна нода дерева та умова її взяття. Миша проходить крізь оверлей у гру. Оверлей видно, лише коли вікно PoE знайдене й активне, і він рухається разом із вікном.
- **Детальне меню (F9).** Повний список кроків з галочками, дерево, ручне коригування рівня й очок, таблиця сплітів, скидання прогресу з підтвердженням. Відкривається праворуч від гри (або біля правого краю, якщо місця немає) і не забирає фокус.
- **Повністю автоматичне відстеження з `Client.txt`** від створення персонажа до кінця Act 10, без ручних відміток (див. нижче). Читаються лише нові рядки, позиція в лозі зберігається між запусками.
- **Таймер забігу.** Остання подія з часом і різницею, поточний час, наступна подія. Порівняння з особистим рекордом (PB), минулим забігом або сумою найкращих сегментів. Зелений — попереду, червоний — позаду, золотий — найкращий сегмент за всю історію.
- **Опції білда.** Мул-Відьма, Shield Charge / Leap Slam, шлях Act 6. Кроки, ноди й спліти фільтруються за обраними опціями.
- **Версії гайдів.** Новий YAML-файл у `~/.poe-helper/guides` одразу з'являється у списку версій.
- **Встановлення і оновлення** через Setup.exe ([Velopack](https://velopack.io)).

## Що відстежується автоматично

Гра пише в `Client.txt` лише частину подій, тому кожен етап прив'язано до рядка, який там точно є (перевірено на повній кампанії з реального логу):

| Етап | Рядок у `Client.txt` | Як використовується |
|---|---|---|
| Зона | `Generating level N area "<ID>"` + `You have entered X.` | Крок маршруту «зона X: дія → далі Z» з'являється при вході в X, закривається при вході в Z або в зону наступного кроку |
| Бос | смерть боса в лог не пишеться | Бос вважається вбитим при вході в зону, яку він відкриває (Merveil → The Southern Forest, Dominus → The Aqueduct, Kitava → Lioneye's Watch A6…) |
| Квест з очком | `You have received a Passive Skill Point.` (`… 2 Passive Skill Points` за An End to Hunger) | Закриває квестовий крок, рахує очки точно |
| Точні очки | `N Passive Skill Points from quests` — відповідь на команду `/passives` | Синхронізація, якщо застосунок запустили посеред кампанії |
| Лабіринт | `Successfully allocated passive skill id: Ascendancy…` | Normal / Cruel / Merciless — 2 / 4 / 6 очок асценду |
| Нода дерева | `Successfully allocated passive skill … name: X` | Нода гайда з `passives: [X]` відмічається сама |
| Новий персонаж | `Requesting to complete all tutorials due to the client setting` — одразу після першого входу на Twilight Strand | Гайд і таймер починаються з нуля (мул — виняток, поки не почався маршрут) |
| Інший персонаж | `[SCENE] Set Source [(unknown)]` (вибір персонажа) + рядок про рівень | Перемикання на прогрес цього персонажа; рівні гравців групи (`X has joined the area`) ігноруються |
| Рівень | `<ім'я> (<клас>) is now level N` | Рівень, підказки гемів, спліти рівня |
| Смерть | `<ім'я> has been slain.` | Лічильник смертей у забігу |
| Час | `[LOADING SCREEN] … Duration = N seconds`, `***** LOG FILE OPENING *****` | Таймер без завантажень і без часу, коли гра закрита |

Підказки білда (геми, вендори, крафти) закриваються самі: коли підказку показали в місті і ви вийшли з міста. Список ніколи не «зависає»: пропущені зони і забуті підказки минулих актів ховаються, а кроки майбутніх актів не з'являються наперед.

Перевірити трекінг на своєму лозі можна інструментом відтворення: він проганяє `Client.txt` через ту саму логіку і показує, що і коли спрацювало.

```bash
dotnet run --project tools/PoeNoobMan.Replay -- --log "C:\Program Files (x86)\Grinding Gear Games\Path of Exile\logs\Client.txt" --guide guides/arma-crema-scion@3.29.2.yaml --char ІмяПерсонажа --opt mule=no --timeline
```

Обмеження:
- **Зони і нагороди в лозі без імені персонажа.** Персонаж визначається за створенням і рядками про рівень. Якщо зайти іншим персонажем, його зони зараховуються поточному, доки він не підніме рівень.
- **Час боса — це момент входу в наступну зону**, а не сам удар, що вбив боса. Для боса, який не відкриває нову зону (Fidelitas, Gravicius, Kaom), — момент переходу в наступну зону маршруту.
- **Підтримується лише англійський клієнт гри.**

## Оверлей

```
┌─────────────────────────────────────────┐
│ A1  The Coast                рів 4 · 3 оч│  акт, зона, рівень, очки
│▌Tidal Island: ⚔ Hailrake                 │  що зробити тут
│▌• WP                                     │
│▌→ The Mud Flats                          │  куди далі
│ ГЕМИ 4   Galvanic Arrow + Mirage Archer  │  підказки білда з мітками
│          • Sniper's Mark · Dash          │
│ КУПИТИ   Nessa: Serrated Arrow Quiver    │
│ НАГОРОДА книга за Dweller — Tarkleigh    │
│ ДЕРЕВО   Gathering Winds — після Lab     │
└─────────────────────────────────────────┘
```

За замовчуванням оверлей розташовано так, щоб не перекривати інтерфейс гри:
- **підказки** — ліворуч, під портретом і рамками групи (27% висоти);
- **таймер** — угорі між смугою здоров'я боса і мінікартою;
- **меню F9** — праворуч від гри, а якщо гра на весь екран, то біля правого краю нижче мінікарти.

Позиції змінюються в розділі «Вигляд оверлею».

Мітки: ГЕМИ (з рівнем), КУПИТИ, КРАФТ, НАГОРОДА, ЛАБ, ПОРАДА, ДАЛІ — що з'явиться з наступним рівнем, ДЕРЕВО — нода. У таймері: ⚔ — бос, → — ключова локація, ★ — лабіринт.

## Гарячі клавіші (за замовчуванням)

| Клавіша | Дія |
|---|---|
| F9 | Детальне меню |
| F10 | Відмітити перший поточний крок |
| Shift+F10 | Скасувати останню відмітку |
| Ctrl+F10 | Відмітити ноду «взяти зараз» |
| F7 | Скопіювати regex вендора з поточного кроку |
| F8 | Таймер: старт / ручний спліт |
| Ctrl+F8 | Таймер: скасувати спліт |
| Shift+F8 | Таймер: скинути (забіг іде в історію) |

Хоткеї працюють лише з увімкненим оверлеєм. Якщо клавішу зайняла інша програма, це буде видно при збереженні налаштувань.

## Встановлення

1. Запустіть `PoeNoobMan-win-Setup.exe`. Якщо на ПК немає .NET 10 Desktop Runtime, інсталятор його поставить.
2. У PoE увімкніть режим **Windowed** або **Windowed Fullscreen**: в ексклюзивному Fullscreen оверлей не видно.
3. У вікні налаштувань:
   - перевірте шлях до `Client.txt` (кнопка «Знайти» шукає його сама);
   - ім'я персонажа можна не вписувати: він визначається з логу, для кожного персонажа ведеться свій прогрес;
   - оберіть білд і опції;
   - натисніть «Зберегти»;
   - натисніть «Увімкнути оверлей».

Підтримується **англійський клієнт гри** (рядки логу розбираються англійською). ID зон у гайді від мови не залежать.

## Дані

Усе лежить у `%USERPROFILE%\.poe-helper`:

```
settings.json        налаштування
log-state.json       до якого місця прочитано Client.txt
guides/*.yaml        ваші гайди (перекривають вбудовані з тим самим id і версією)
progress/*.json      прогрес: <гайд>__<персонаж>.json
runs/current.json    поточний забіг
runs/<гайд>/*.json   історія забігів для порівняння
app.log              журнал помилок
```

## Формат гайда

Маршрут кампанії (усі зони Act 1–10, квести, боси, лабіринти, спліти) лежить окремо в `guides/routes/campaign@3.29.yaml` і спільний для всіх білдів. Гайд білда додає лише свої кроки й вставляє кожен після потрібного кроку маршруту:

```yaml
id: arma-crema-scion
version: "3.29.2"
title: Arma Crema Scion
route: campaign@3.29                 # маршрут з guides/routes/
options:
  - id: movement
    label: Пересування
    default: shield_charge
    choices:
      - { id: shield_charge, label: Shield Charge }
      - { id: leap_slam, label: Leap Slam }
steps:
  - id: mule_create
    after: "^"                       # на самий початок, перед маршрутом
    act: 1
    done: { area: "1_1_town" }
    text: "Мул: створіть Відьму, вбийте Hillock"
  - id: a1_l10_sc
    after: a1_upper                  # після кроку маршруту Upper Prison
    act: 1
    when: { level: 10 }              # з'являється з 10 рівня
    if: { movement: shield_charge }  # лише для цієї гілки
    kind: gems                       # мітка: gems | buy | craft | tip
    text: "Shield Charge + Faster Attacks + Momentum · щит у дорозі"   # « · » — окремі пункти; без done — підказка
  - id: a4_kaom_level
    after: a4_kaomdream
    act: 4
    when: { area: "1_4_4_1" }
    done: { level: 32 }
    text: "Набийте 32 рівень до Kaom's Stronghold"
tree:
  - id: heart_and_soul
    name: "Practical Application, Heart and Soul, Fire Walker"
    when: { points: 61 }
    passives: ["Practical Application", "Heart and Soul", "Fire Walker"]   # відмітиться сама
```

Крок маршруту виглядає так:

```yaml
  - id: a1_anger
    act: 1
    when: { area: "1_1_11_2" }       # з'являється при вході в Cavern of Anger
    done: { area: "1_2_1" }          # закривається при вході в The Southern Forest (Merveil убитий)
    text: "Cavern of Anger: вбийте Merveil → The Southern Forest (Act 2)"
  - id: q1_dweller
    act: 1
    when: { area: "1_1_4_0" }
    points: 1                        # закривається рядком про отримане очко
    text: "Нагорода: книга за Dweller у Tarkleigh (+1)"
```

Умови `when`, `done` і `on`:

| Поле | Значення |
|---|---|
| `level` | рівень персонажа |
| `points` | очки дерева |
| `area` | ID зони або її назва |
| `step` | інший крок виконано |
| `passive` | взято пасивку з такою назвою |
| `ascendancy` | взято N очок асценду: 2, 4 або 6 |

Якщо задано кілька полів, мають виконатися всі. Без `done` крок є підказкою: він закривається, коли його показали в місті й ви вийшли з міста.

ID зон беруться з рядків `Generating level N area "<ID>"` у `Client.txt`. Наприклад: `1_1_town` — Lioneye's Watch в Act 1, `2_6_town` — в Act 6, `2_11_endgame_town` — Karui Shores.

При завантаженні гайд перевіряється: невідомі опції, повторені id, посилання на неіснуючі кроки. Помилки видно у вікні налаштувань.

## Розробка

Потрібен .NET 10 SDK.

```bash
dotnet build PoeNoobMan.slnx
```

```bash
dotnet test tests/PoeNoobMan.Core.Tests
```

```bash
dotnet run --project src/PoeNoobMan.App
```

Структура:
- `src/PoeNoobMan.Core` — логіка без інтерфейсу: читання логу, гайди, прогрес, спліти. Покрита тестами.
- `src/PoeNoobMan.App` — WPF: вікна, Win32-оверлей, хоткеї, оновлення.
- `guides/` — вбудовані гайди, `guides/routes/` — маршрут кампанії (копіюються в `Guides/` поруч з exe).
- `tools/PoeNoobMan.Replay` — відтворення `Client.txt` для перевірки трекінгу.

Перевірити вигляд оверлею, таймера і меню без запуску гри (нічого не показує і не зберігає, пише PNG):

```bash
PoeNoobMan.exe --preview C:\temp\preview
```
- `build/pack.ps1` — збирання інсталятора.
- `build/make-icon.ps1` — малює іконку (`src/PoeNoobMan.App/Assets/icon.ico`, `icon.png`).

## Реліз і оновлення

```powershell
./build/pack.ps1 -Version 0.1.0
```

Результат у `releases/`: `PoeNoobMan-win-Setup.exe` для встановлення, а також `*.nupkg` і `releases.win.json` для оновлень.

Публікація на GitHub (застосунок сам знайде оновлення в GitHub Releases):

```powershell
$env:GITHUB_TOKEN = "<token з правом contents:write>"
./build/pack.ps1 -Version 0.2.0 -RepoUrl https://github.com/<you>/POENoobMAN -Publish
```

Потім у налаштуваннях застосунку, у полі «Джерело оновлень», вкажіть посилання на репозиторій. Також підійде URL або локальна чи мережева папка з вмістом `releases/`.
